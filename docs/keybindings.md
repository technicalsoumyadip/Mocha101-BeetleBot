# Keybindings Reference

The **Super (Windows)** key is the primary modifier for BrewLand.

## General & System
| Keybinding | Action |
| :--- | :--- |
| `Super + Return` | Open Terminal (Kitty) |
| `Super + Q` | Close Active Window |
| `Super + X` | Exit Hyprland Session |
| `Super + Shift + L` | Lock Screen (Hyprlock) |
| `Super + R` | Reload Waybar & SwayNC |
| `Super + Shift + Z` | Toggle Theme (Mocha/Latte) |

## Applications
| Keybinding | Action |
| :--- | :--- |
| `Super + W` | Browser (Zen Browser) |
| `Super + E` | File Manager (Thunar) |
| `Super + C` | Editor (VSCodium) |
| `Super + O` | Notes (Obsidian) |
| `Super + Alt + N` | Network Menu (Impala) |
| `Super + Alt + B` | Bluetooth Menu (Bluetui) |

## Rofi Menus
| Keybinding | Action |
| :--- | :--- |
| `Super + Space` | Application Launcher |
| `Super + /` | Clipboard History |
| `Super + .` | Emoji Picker |
| `Super + Shift + SPACE` | File Search |
| `Super + Shift + P` | Package & Update Menu |
| `Super + Shift + W` | Wallpaper Picker |
| `Super + Shift + X` | Power Menu |

## Window Management
- **Move Focus**: `Super + Arrow Keys`
- **Toggle Floating**: `Super + V`
- **Move Window**: `Super + Left Click (Drag)`
- **Resize Window**: `Super + Right Click (Drag)`
- **Magic Shelf**: `Super + S` (Toggle) / `Super + Shift + S` (Send Window)

---
*For the complete configuration, see `hypr/HLconfigs/keybindings.conf`.*
